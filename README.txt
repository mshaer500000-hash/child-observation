برنامج ملاحظة الطفل - نسخة قابلة للنشر

الملفات:
- index.html : البرنامج
- manifest.webmanifest : إعدادات تثبيت التطبيق
- sw.js : العمل دون اتصال بعد أول فتح
- icon-192.png و icon-512.png : أيقونات التطبيق

طريقة النشر:
يمكن رفع المجلد كما هو إلى GitHub Pages أو Netlify أو Vercel أو أي استضافة مواقع ثابتة.
لا يحتاج قاعدة بيانات أو خادم في النسخة الحالية؛ البيانات تحفظ محليًا في جهاز المستخدم.
